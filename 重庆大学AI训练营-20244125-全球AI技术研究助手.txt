全球AI技术研究助手

基于 Nexent + SiliconFlow + ModelScope MCP + Exa.ai 四引擎打造的中英双语全栈AI技术研究智能体

GitHub: https://github.com/HGTRs777/Global-AI-Tech-Research-Assistant


一句话简介

输入一个技术问题或研究方向，自动对中英文技术生态进行全景搜索、深度分析，输出结构化研究报告。


为什么要做这个智能体？

当前 AI 技术发展日新月异，但研究者面临三大痛点：

1. 信息孤岛 —— 中文技术社区（CSDN、知乎、公众号）与国际社区（arXiv、GitHub、Hacker News）信息割裂
2. 工具碎片 —— 需要同时打开多个搜索引擎、代码仓库、论文网站，切换成本高
3. 深度不足 —— 传统搜索只能返回链接列表，无法进行跨源综合分析和结构化输出

这个智能体通过 Nexent（Agent 运行时）+ Exa.ai（国际搜索）+ ModelScope MCP（国内生态）+ SiliconFlow（模型推理）四引擎协同，一步到位解决上述问题。

模型配置（均通过 SiliconFlow API）

【LLM 大语言模型 —— 决策大脑】
  模型: deepseek-ai/DeepSeek-V3
  提供商: SiliconFlow（硅基流动）
  API: https://api.siliconflow.cn/v1/chat/completions
  用途: 复杂推理、技术分析、报告生成
  备选: Qwen/Qwen3-235B-A22B（适合长上下文文档分析）

【Embedding 向量模型 —— 知识检索】
  模型: BAAI/bge-m3
  提供商: SiliconFlow
  用途: 知识库文档向量化、语义检索
  说明: BGE-M3 支持中英双语，8192 token 长文本嵌入

【VLM 视觉模型 —— 图表理解】
  模型: Qwen/Qwen2.5-VL-72B-Instruct
  提供商: SiliconFlow
  用途: 解析论文中的架构图、表格、Benchmark 截图


MCP 工具配置

工具组 A：Exa.ai MCP（国际技术搜索）

  MCP Server: exa-search
  运行方式: npx @anthropic-ai/mcp-server-exa
  所需环境变量: EXA_API_KEY=你的Exa密钥

  注册的工具:
  · exa_search —— AI语义搜索，搜索前沿论文、技术博客、开源项目
  · exa_answer —— 直接生成答案，快速获取技术定义的精确回答
  · exa_deep_search —— 深度研究，大型技术主题的全面调研
  · exa_code_search —— 代码搜索，查找 GitHub 上的实现代码

工具组 B：ModelScope MCP（中文技术生态）

  MCP Server 1: 秘塔搜索 (Metaso Search)
  MCP URL: https://api.modelscope.cn/mcp/metaso-search/sse
  工具: metaso_search，支持简单/深度/研究三种模式
  用途: 搜索中文技术文章、知乎讨论、公众号内容

  MCP Server 2: Trends Hub（热点聚合）
  MCP URL: https://api.modelscope.cn/mcp/trends-hub/sse
  工具: get_trends
  用途: 获取 GitHub Trending、知乎热榜、36氪等 20+ 平台热点

  MCP Server 3: Markdownify（文档转换）
  MCP URL: https://api.modelscope.cn/mcp/markdownify/sse
  工具: convert_to_markdown
  用途: 将搜索到的 PDF 论文、网页转文本供 LLM 分析

  MCP Server 4: Fetch MCP（网页抓取）
  MCP URL: https://api.modelscope.cn/mcp/fetch/sse
  工具: fetch_url
  用途: 抓取特定技术文章全文进行深度分析

System Prompt 设计

以下 Prompt 可通过 Nexent 的 NL2Agent 自动生成，也可手动精调。直接复制到 Nexent 智能体配置的「角色定义」和「使用要求」字段中即可。

===== 角色定义 =====

你是「全球AI技术研究助手」，一个专注于 AI 基础设施（算力虚拟化、智能体平台、数据处理）领域的技术研究智能体。你能够同时检索中英文技术生态，进行深度分析并输出结构化研究报告。

===== 核心能力 =====

1. 双语搜索：通过 Exa.ai 搜索国际前沿论文、开源项目、技术博客；通过秘塔搜索中文技术社区内容
2. 代码理解：通过 Exa Code Search 查找相关实现代码，并进行解读
3. 文档解析：将 PDF/网页转换为可读文本，提取关键技术细节
4. 综合分析：交叉验证中英文信息源，生成对比分析
5. 结构化输出：以研究报告格式输出，包含摘要、技术对比表、代码示例、参考文献

===== 工作流程 =====

1. 收到用户问题后，先拆解核心关键词
2. 同时发起 Exa.ai（英文）和秘塔搜索（中文）查询
3. 对高价值链接使用 Fetch 抓取全文
4. 用 Markdownify 转换非文本格式文档
5. 综合所有信息，使用 DeepSeek-V3 进行深度分析
6. 按结构化模板输出研究报告
7. 附上所有参考来源（标题 + URL）

===== 输出模板 =====

一、研究摘要
（200字以内概括核心发现）

二、技术背景
（相关技术的演进脉络和关键概念）

三、核心对比分析

  维度    | 方案A     | 方案B
  --------|-----------|----------
  xxx     | xxx       | xxx

四、代码示例
（关键实现的代码片段及解读）

五、社区生态对比
（GitHub Star、贡献者、社区活跃度）

六、结论与建议

七、参考文献
· 标题 — 来源URL
· ...

===== 约束规则 =====

· 必须标注每条信息的来源链接
· 对时效性敏感的话题，优先返回最近 6 个月的内容
· 如果中英文信息存在矛盾，明确指出并分析可能原因
· 中文回复，但技术术语保留英文原名并附中文解释
· 代码块标注语言类型

部署方式

前提条件：

  · SiliconFlow API Key —— 注册即送额度 (cloud.siliconflow.cn)
  · Exa.ai API Key —— 注册获取 (exa.ai)
  · ModelScope MCP —— 免费使用 (modelscope.cn/mcp)
  · Nexent 平台 —— 开源部署

部署步骤：

  1. 克隆并部署 Nexent（Docker 方式，2C6G 即可）
     git clone https://github.com/ModelEngine-Group/nexent.git
     cd nexent/docker
     cp .env.example .env
     编辑 .env 填入 SiliconFlow API Key
     bash deploy.sh

  2. 访问 Nexent 控制台 http://localhost:3000/zh

  3. 在 Nexent 中按以下顺序操作：
     ① 模型接入 → 填入 SiliconFlow API Key → 测试连通性
     ② MCP 工具 → 依次添加 Exa.ai + 秘塔搜索 + Fetch + Markdownify
     ③ 知识库 → 上传 Flex:AI / Nexent / DataMate 相关文档
     ④ 生成智能体 → 粘贴 System Prompt → 点击「生成智能体」
     ⑤ 调试 → 发送测试问题 → 观察工具调用链
     ⑥ 发布 → 发布到智能体市场供同学使用


扩展方向

  · 论文翻译 —— 自动翻译英文论文摘要为中文（利用 SiliconFlow 翻译能力）
  · 代码复现 —— 自动 clone 仓库 → 运行 Demo → 输出结果（搭配 Playwright MCP）
  · 日报生成 —— 每日自动扫描技术热点 → 推送日报（搭配 Trends Hub + 定时任务）
  · 视频解读 —— 解析技术演讲视频 → 提取要点（搭配 YouTube MCP + Whisper）
  · SQL分析 —— 对接数据库进行量化分析（搭配 XiYan Text-to-SQL MCP）

工具与模型说明

本智能体由 Claude Code 驱动设计，底层推理模型为 DeepSeek-V3。设计过程中利用 Claude Code 的多工具协同能力完成 Nexent Discussion 格式调研、四引擎架构设计、System Prompt 精调及纯文本排版，再由 DeepSeek-V3 对技术细节和中文表述进行深度校验，确保结构完整、表达地道、即拷即用。


设计者注

这个智能体将 Exa.ai 的国际前沿搜索能力、ModelScope MCP 的中文技术生态覆盖能力、SiliconFlow 的多模型推理能力整合为一个研究闭环，实现中英文技术信息的无缝衔接。四个工具各司其职，旨在抹平 AI 技术领域的语言和信息鸿沟。
