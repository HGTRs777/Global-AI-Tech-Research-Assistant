Nexent 智能体配置操作指南
================================

访问地址: http://localhost:3000


第一步：配置模型（SiliconFlow 硅基流动）

1. 登录 Nexent 控制台后，进入左侧菜单「模型管理」
2. 依次添加以下三个模型提供商（均使用 SiliconFlow）：

   【LLM - 大语言模型】
   - 提供商: OpenAI 兼容
   - API Key: （填写你的 SiliconFlow API Key）
   - API Endpoint: https://api.siliconflow.cn/v1
   - 模型: deepseek-ai/DeepSeek-V3
   - 用途: 对话

   【Embedding - 向量模型】
   - 提供商: OpenAI 兼容
   - API Key: 同上
   - API Endpoint: https://api.siliconflow.cn/v1/embeddings
   - 模型: BAAI/bge-m3
   - 用途: 向量化

   【VLM - 视觉模型】
   - 提供商: OpenAI 兼容
   - API Key: 同上
   - API Endpoint: https://api.siliconflow.cn/v1
   - 模型: Qwen/Qwen2.5-VL-72B-Instruct
   - 用途: 多模态

3. 保存配置，点击「连通性校验」确认每个模型连接成功


第二步：配置 MCP 工具

进入左侧菜单「MCP工具」或在智能体开发页面内操作。

【MCP 1 - Exa.ai 国际搜索】

Exa.ai 需要通过本地 MCP Server 方式接入，因为它需要 Node.js 运行环境。

在 Nexent 的 MCP 配置页面，选择「本地 MCP 工具」→「添加」：
- 工具名称: Exa 国际搜索
- 运行方式: npx
- 命令: npx @anthropic-ai/mcp-server-exa
- 环境变量: EXA_API_KEY=你的Exa密钥

【MCP 2 - 秘塔搜索 (Metaso Search)】

选择「远程 MCP 工具」→「添加」：
- 名称: 秘塔搜索
- URL: https://api.modelscope.cn/mcp/metaso-search/sse
- 传输协议: SSE
- 点击「连通性校验」

【MCP 3 - Trends Hub 热点聚合】

- 名称: 热点聚合
- URL: https://api.modelscope.cn/mcp/trends-hub/sse
- 传输协议: SSE

【MCP 4 - Fetch MCP 网页抓取】

- 名称: 网页抓取
- URL: https://api.modelscope.cn/mcp/fetch/sse
- 传输协议: SSE

所有 MCP 添加完成后，依次点击连通性校验，确认均为「连接成功」。


第三步：创建知识库

进入左侧菜单「知识库」→「创建知识库」：

知识库一：AI基础设施
- 上传文件: Flex:AI 技术文档、Nexent 文档、DataMate 文档等

知识库二：模型生态
- 上传文件: DeepSeek 官方文档、Qwen 文档、NVIDIA 文档等

上传后系统会自动切片、向量化，并生成知识库概览摘要。


第四步：创建智能体

进入左侧菜单「智能体空间」→「创建智能体」：

1. 选择「自然语言生成智能体」

2. 在描述框中粘贴以下内容：
   "做一个全球AI技术研究助手，能够使用Exa国际搜索和秘塔中文搜索
   进行双语技术调研，抓取网页全文，聚合技术热点，输出结构化研究报告。
   专注于AI基础设施领域（算力虚拟化、智能体平台、数据处理）。"

3. 点击「生成智能体」，系统会自动生成 System Prompt

4. 在智能体配置中挂载：
   - 模型: DeepSeek-V3
   - 向量模型: BGE-M3
   - 视觉模型: Qwen2.5-VL-72B
   - 知识库: 勾选「AI基础设施」和「模型生态」
   - MCP工具: 勾选 Exa搜索、秘塔搜索、Trends Hub、Fetch

5. 进入「手动调优」模式，将 System Prompt 替换为以下内容：

===== 角色定义 =====

你是「全球AI技术研究助手」，一个专注于 AI 基础设施（算力虚拟化、
智能体平台、数据处理）领域的技术研究智能体。你能够同时检索中英文
技术生态，进行深度分析并输出结构化研究报告。

===== 核心能力 =====

1. 双语搜索：通过 Exa.ai 搜索国际前沿论文、开源项目、技术博客；
   通过秘塔搜索中文技术社区内容
2. 代码理解：通过 Exa Code Search 查找相关实现代码，并进行解读
3. 文档解析：将 PDF/网页转换为可读文本，提取关键技术细节
4. 综合分析：交叉验证中英文信息源，生成对比分析
5. 结构化输出：以研究报告格式输出，包含摘要、技术对比表、代码
   示例、参考文献

===== 工作流程 =====

1. 收到用户问题后，先拆解核心关键词
2. 同时发起 Exa.ai（英文）和秘塔搜索（中文）查询
3. 对高价值链接使用 Fetch 抓取全文
4. 综合所有信息，使用 DeepSeek-V3 进行深度分析
5. 按结构化模板输出研究报告
6. 附上所有参考来源（标题 + URL）

===== 输出模板 =====

一、研究摘要（200字以内概括核心发现）

二、技术背景（相关技术的演进脉络和关键概念）

三、核心对比分析（表格形式，含维度、方案对比）

四、代码示例（关键实现的代码片段及解读）

五、社区生态对比（GitHub Star、贡献者、社区活跃度）

六、结论与建议

七、参考文献（标题 + 来源URL）

===== 约束规则 =====

- 必须标注每条信息的来源链接
- 对时效性敏感的话题，优先返回最近 6 个月的内容
- 如果中英文信息存在矛盾，明确指出并分析可能原因
- 中文回复，但技术术语保留英文原名并附中文解释
- 代码块标注语言类型


第五步：调试与测试

1. 在智能体对话框中发送测试问题：
   "帮我调研 Flex:AI 和 NVIDIA MIG 在 GPU 虚拟化上的技术差异"

2. 观察智能体的思考链（Thought → Action → Observation）：
   - 是否并行调用了 Exa 搜索和秘塔搜索
   - 是否对关键页面调用了 Fetch
   - 输出是否遵循了结构化模板

3. 如果工具调用失败：
   - 检查 MCP 连通性
   - 确认 API Key 有效
   - 查看右上角运行日志

4. 调试完成后，点击「发布」→ 填写版本号 → 发布到智能体市场


第六步：发布到智能体市场（可选）

1. 在智能体页面点击「发布」
2. 填写版本号 v1.0.0
3. 添加描述和标签：AI基础设施、技术研究、双语搜索
4. 确认发布
5. 其他同学即可在「智能体市场」中下载使用你的智能体
